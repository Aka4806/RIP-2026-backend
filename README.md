# SQL Index ЛР2

Go / Gin, PostgreSQL, GORM, HTML-шаблоны, CSS и MinIO.

Веб-приложение для просмотра и управления конфигурациями индексов B-tree, Hash и Bitmap. Данные хранятся в PostgreSQL, изображения и видео — в MinIO. Страницы формируются на сервере с использованием HTML-шаблонов.

## Запуск

Перед запуском должны быть подготовлены база rip_lab2 с таблицами и пользователями и хранилище MinIO с медиафайлами.

В PowerShell из папки проекта:

```powershell
$env:PGPASSWORD="пароль PostgreSQL"
$env:PGDATABASE="rip_lab2"
$env:CURRENT_USER_ID="2"
$env:MEDIA_BASE_URL="http://localhost:9000/media"
go mod download
go run ./cmd/awesomeProject
```

Приложение: http://127.0.0.1:18080/indexes

Необязательные переменные: PGHOST (localhost), PGPORT (5432), PGUSER (postgres), PGSSLMODE (disable), APP_ADDR (127.0.0.1:18080).

Схема базы и начальные данные должны существовать до запуска приложения. Автоматическое создание таблиц при запуске не выполняется.

## Текущий пользователь

Текущий пользователь задаётся переменной CURRENT_USER_ID. Значение по умолчанию — 2. Пользователь с указанным ID должен существовать в таблице users.

Его ID используется при создании черновика и проверке принадлежности карточки. Полноценная аутентификация реализуется в следующих лабораторных работах.

## Страницы приложения

| URL | Назначение |
|---|---|
| `/indexes` | Плитка опубликованных конфигураций и фильтр |
| `/feed/` | Лента опубликованных конфигураций |
| `/feed/{id}` | Просмотр выбранной карточки |
| `/add` | Создание и просмотр собственного черновика |

В плитке доступна фильтрация по размеру таблицы. В ленте отображаются изображение, видео, описание, параметры конфигурации и количество лайков.

## Методы работы с карточками

| Метод | URL | Назначение |
|---|---|---|
| GET | `/indexes` | Получение страницы списка |
| GET | `/feed/` или `/feed/{id}` | Получение страницы ленты |
| GET | `/add` | Получение страницы черновика |
| POST | `/indexes` | Создание черновика |
| POST | `/indexes/{id}/publish` | Заполнение параметров и публикация |
| POST | `/indexes/{id}/delete` | Удаление собственной карточки |

Данные форм обрабатываются сервером. После успешного изменения выполняется перенаправление на соответствующую страницу.

## Таблицы PostgreSQL

| Таблица | Назначение |
|---|---|
| users | Пользователи |
| index_configurations | Конфигурации индексов |
| index_configuration_likes | Лайки пользователей |

Конфигурация связана с пользователем-создателем. Таблица лайков связывает пользователей и конфигурации индексов.

Создание карточки устанавливает состояние draft. После заполнения необходимых параметров карточка переводится в published и становится доступна в списке и ленте. При удалении устанавливается состояние deleted.

## Структура проекта

- `cmd/awesomeProject` — запуск сервера.
- `internal/api` — маршруты приложения.
- `internal/database` — подключение к PostgreSQL.
- `internal/app/handler` — обработчики запросов и проверка данных.
- `internal/app/repository` — операции с базой данных.
- `internal/app/models` — модели таблиц.
- `internal/app/media` — формирование адресов медиа.
- `templates` — HTML-шаблоны.
- `resources` — стили и статические файлы.
