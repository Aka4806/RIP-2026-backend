# SQL Index ЛР1

Go / Gin, HTML-шаблоны, CSS и MinIO.

Веб-интерфейс для просмотра конфигураций индексов B-tree, Hash и Bitmap для таблиц разных размеров. Данные конфигураций хранятся в памяти приложения, изображения и видео загружаются из MinIO. PostgreSQL в этой работе не используется.

## Запуск

В PowerShell из папки проекта:

```powershell
go mod download
go run ./cmd/awesomeProject
```

Приложение: http://127.0.0.1:18080/indexes

Для медиа по умолчанию используется адрес http://localhost:9000/media. MinIO должен быть запущен, бакет media и используемые объекты должны быть доступны для чтения из браузера.

Другой адрес хранилища можно задать перед запуском:

```powershell
$env:MEDIA_BASE_URL="http://localhost:9000/media"
```

Необязательная переменная APP_ADDR задаёт адрес сервера. Значение по умолчанию — 127.0.0.1:18080.

## Страницы приложения

| URL | Назначение |
|---|---|
| `/indexes` | Плитка конфигураций с фильтром по размеру таблицы |
| `/feed/` | Первая карточка ленты |
| `/feed/{id}` | Просмотр карточки по ID |
| `/add` | Отображение черновика |

Лента без ID и по ID — варианты одной страницы. Для перехода к следующей карточке используется `/feed/{id}?next=true`.

В плитке отображаются изображения, названия, размеры таблиц, селективность и количество лайков. Нажатие на карточку открывает её в ленте. Лента содержит изображение, видео, описание и параметры конфигурации.

## Данные

Конфигурации заданы в `internal/app/repository/repository.go`. Приложение использует подготовленные данные без обращения к базе данных.

Страница черновика отображает заранее подготовленную конфигурацию. Сохранение новых карточек, публикация, удаление и аутентификация в этой версии не реализованы.

## Структура проекта

- `cmd/awesomeProject` — запуск сервера.
- `internal/api` — настройка маршрутов и HTML-шаблонов.
- `internal/app/handler` — обработчики запросов.
- `internal/app/repository` — подготовленные данные и выборка конфигураций.
- `templates` — HTML-шаблоны страниц.
- `resources` — стили и статические файлы.
